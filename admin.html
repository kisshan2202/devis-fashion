Connect GitHub to publish

Do this once on each phone or computer you use. The key is saved only on this device.

  1. In Chrome, sign in at github.com. The GitHub app can't make access keys, so use the browser.
  2. Open this ready-filled access key page. The name, expiry and permission are already set.
  3. Under Repository access, choose Only select repositories and pick date-guru.
  4. Scroll down, tap Generate token, copy the key, and paste it below.

Seeing "Page not found"? You're not signed in on this browser. Sign in first, then open the link again. Or go the long way: profile picture, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. In that case also set Contents to Read and write under Permissions.
