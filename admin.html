Connect GitHub to publish

Do this once on each phone or computer you use. The key is saved only on this device.

  1. Open GitHub's new fine-grained token page (sign in if asked).
  2. Name it Devi's Fashion admin and pick an expiry date, for example one year.
  3. Under Repository access, choose Only select repositories and pick date-guru.
  4. Under Permissions, add Contents and set it to Read and write.
  5. Tap Generate token, copy it, and paste it below.
