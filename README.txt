DEVI'S FASHION WEBSITE
======================

What's in this folder
---------------------
index.html     The home page customers see (carousel, all dresses, zoom).
admin.html     The photo manager. Use it to add, delete and reorder photos.
gallery.js     The list of photos and their order. admin.html writes this for you.
images/        The photos. The sample-*.svg files are placeholders; delete them
               in admin.html once real photos are in.
assets/        Styles and scripts. No need to touch these.

Updating photos
---------------
1. Open admin.html from THIS folder on your computer (double-click it).
2. Add photos, drag them into order, add captions and prices, delete old ones.
3. Click "Download update". You get a .zip file.
4. Unzip it into this folder and choose "replace" when asked.
5. Upload the whole folder to your hosting.

Keep this folder on your computer as the master copy. The home page always
shows photos in the same order as admin.html.

Putting the site online (free options)
--------------------------------------
- Netlify Drop: go to app.netlify.com/drop and drag this folder onto the page.
- GitHub Pages, Cloudflare Pages, or any normal web host also work.
You can leave admin.html out of the upload if you prefer: it only ever
changes files on your own computer.

Checking it before uploading
----------------------------
Double-click index.html to see the site in your browser.
